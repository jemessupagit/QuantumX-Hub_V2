# 🥔 QuantumX Hub V3.0 - Semi-potato graphic
### Advanced Mobile & PC Performance Core for Roblox

**By JamesZZS222** | **Version: 3.0.0** | **Open Source**

📖 Description
QuantumX Hub V3 is a lightweight performance booster for Roblox on low-end devices. It reduces graphics, removes unnecessary effects, and optimizes memory to increase FPS from 1-9 up to 30-60+. Features Low/Medium/Super modes, Auto-clean memory, and real-time FPS display. No external software required.

⚠️ Warning & Disclaimer
1. **Use at your own risk.** This script modifies client-side graphics only. It does not exploit or give unfair gameplay advantages.
2. **Visual Changes:** Super Potato Mode will make your game look gray and remove textures. This is normal and intended for max FPS.
3. **Game Compatibility:** May not work properly in games with custom anti-cheat or heavy streaming. If you experience bugs, use `RESET TO DEFAULT`.
4. **Performance varies**
